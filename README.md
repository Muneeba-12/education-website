# Educator — Modern Online Education Platform

![Educator Banner](https://images.unsplash.com/photo-1523240795612-9a054b0db644?w=1200&auto=format&fit=crop&q=80)

**"Learn Today. Build Your Future."**

**Educator** is a complete, modern, and responsive multi-page education & e-learning website built purely using **HTML5**, **CSS3**, and **Vanilla JavaScript** (no frameworks).

---

## 🚀 Live Pages Included

1. **`index.html`** — Homepage with Top Information Bar, Navbar, Hero Section, Feature Cards, Welcome Section, Popular Courses, Why Choose Us, 4-Step Roadmap, Instructors, Student Testimonials Carousel, Statistics Animated Counters, CTA Banner & Footer.
2. **`courses.html`** — Complete course catalog with live search, category pills, level filters, price filters, rating filters, sort options, and wishlist toggle.
3. **`course-details.html`** — Course overview, curriculum accordion, requirements, projects, instructor spotlight, rating distribution breakdown, and enrollment simulation.
4. **`instructors.html`** — Faculty directory with real-time search and department filtering.
5. **`instructor.html`** — Detailed instructor profile with bio, ratings, skills, and instructor courses.
6. **`about.html`** — Mission, vision, core values, company growth timeline (2021–2026), and executive team.
7. **`contact.html`** — Campus info, contact form with live validation, toast alerts, and FAQ accordion.
8. **`blog.html`** — Learning insights hub with category filtering and read times.
9. **`blog-details.html`** — Full article view with code blocks, quotes, author info, and comments.
10. **`login.html`** — Login card with validation, password show/hide, and demo credentials autofill.
11. **`register.html`** — Account registration with real-time password strength meter and role selection.
12. **`dashboard.html`** — Student dashboard with learning stats, SVG study hours chart, and progress tracking.
13. **`certificates.html`** — Verifiable credential gallery and printable official certificate modal.
14. **`profile.html`** — Student profile, achievements, skill badges, and profile editing.

---

## 🛠️ Technology Stack

- **HTML5**: Semantic markup, accessible forms, structured metadata.
- **CSS3**: Modern CSS variables (design tokens), Flexbox, CSS Grid, smooth micro-interactions, responsive breakpoints (`style.css` & `responsive.css`).
- **Vanilla JavaScript**: Pure JS modules for navigation drawer, search modal, stats counter, testimonial carousel, filters, auth validation, SVG charts, and certificate generator (`main.js`, `courses.js`, `auth.js`, `dashboard.js`).

1. Clone the repository:
